### 🚀 Projetos em Destaque

#### 🤖 [B2B Intelligence — Agente de Prospecção & Painel Comercial](https://vinicius-b2b-ai.conectaweb.workers.dev)
Solução completa criada para eliminar a prospecção manual sem critério e acelerar abordagens comerciais reais.
* **O que faz:** Um agente de IA pesquisa, avalia e classifica oportunidades B2B em nuvem, alimentando um dashboard web com indicadores, busca dinâmica, filtros e paginação.
* **Por baixo do capô:** JavaScript (Fetch API), Cloudflare Workers, integração com API externa e fluxo automatizado de dados.

#### 🗂️ Sistema de Inventário de TI — API REST & Banco Relacional
Aplicação full-stack em evolução para controle patrimonial de equipamentos, status operacional, colaboradores e chamados técnicos.
* **O que faz:** Centraliza o ciclo de vida dos ativos de TI com cadastro, edição, filtros e rastreabilidade.
* **Por baixo do capô:** Node.js, Express.js, MySQL (consultas relacionais com `JOIN`), arquitetura REST e testes de rotas via Bruno.

#### ⚡ [Landing Pages de Alta Conversão — Vinicius Web Studio](https://estetica-automotiva.conectaweb.workers.dev)
Desenvolvimento e entrega de páginas rápidas para empresas locais reais transformarem visitas do Google Maps e Instagram em orçamentos no WhatsApp.
* **O que faz:** Interfaces mobile-first com animações em CSS/SVG, comparador interativo de *Antes e Depois* e CTAs direcionados por serviço.
* **Por baixo do capô:** HTML5 semântico, CSS3 modular e JavaScript puro (Vanilla JS) focado em performance.
